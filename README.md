# Quest English Trial Lesson

Локальная консоль пробного урока с индивидуальной карточкой ученика.

## Запуск

```bash
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

Для другого компьютера в той же сети используйте LAN-адрес, который сервер напечатает при запуске, например `http://172.20.10.4:4173`. Адрес `127.0.0.1` работает только на компьютере, где запущен сервер.

## Генерация профиля

Ключ хранится только в `.env.local` и не попадает в браузер или Git. Для другого ключа измените `STUDENT_IMAGE_API_KEY`. Адрес сервиса и модель также настраиваются через `STUDENT_IMAGE_API_BASE_URL` и `STUDENT_IMAGE_MODEL`.

Фото ученика необязательно. При наличии фото оно уменьшается локально перед отправкой, а итоговая иллюстрация создаётся заново для каждого нового профиля и каждой команды `REGENERATE`.
